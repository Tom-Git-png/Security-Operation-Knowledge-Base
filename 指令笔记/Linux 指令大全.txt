一、系统基础信息（判断系统版本、运行状态）。

uname -a  # 内核版本，看内核漏洞风险。
hostname。
id  # 当前执行用户权限。
whoami。
uptime  # 系统开机多久，判断入侵时间参考。

二、账号安全排查（暴力破解、新增可疑账号）。

cat /etc/passwd  # 全部账号，看陌生账号。
cat /etc/shadow  # 密码哈希。
last  # 登录历史，谁登录过。
last boot  # 开始系统开机记录。
groups  # 当前用户所属组。
id 加用户名  # 查看某个用户uid/gid。

三、进程排查（恶意进程、木马、异常后台）。

ps aux  # 完整进程列表，最常用。
ps -ef。
top  # 实时CPU内存占用。
htop  # 增强top（可选）。
pgrep nginx  # 按名字查进程PID。
ls /proc/$PID/  # 查看某个进程详情、执行路径。

四、网络排查（对外连接、监听端口、后门端口）。

ip a  # 网卡IP。
ip route  # 路由。
ss -tulnp  # 【高频】查看所有监听端口，看可疑对外开放端口。
netstat -tulnp  # 老版本系统使用。
ss -an  # 全部网络连接，看恶意外联。
iptables -L -n  # 防火墙规则，是否有异常放行。

五、文件权限，提权风险排查。

find / -perm -4000 2>/dev/null  # 查找SUID文件，提权风险。
find / -perm -2000 2>/dev/null  # SGID文件。
ls -l /etc/crontab。
ls -la /tmp  # /tmp目录经常放恶意脚本。

六、定时任务（持久化后门，挖矿木马最爱）。

crontab -l  # 当前用户定时任务。
cat /etc/crontab。
ls /etc/cron.d/。
ls /etc/cron.hourly/。
ls /etc/cron.daily/。
ls /etc/cron.weekly/。
ls /etc/cron.monthly/。

七、日志排查（SOC 运营核心，验证 SIEM 告警）。

systemd 系统使用 journalctl，老系统看 /var/log。
journalctl -xe  # systemd系统全部系统日志。
journalctl -u sshd  # 只看ssh登录日志。
tail -f /var/log/messages  # 实时系统日志。
tail -200 /var/log/secure  # ssh登录日志(CentOS重点！暴力破解看这里)。
tail -200 /var/log/auth.log  # Ubuntu登录认证日志。
grep "Failed password" /var/log/secure  # 搜索ssh失败爆破。
grep "Accepted password" /var/log/secure  # 成功登录。

八、磁盘与文件排查。

df -h  # 磁盘占用，挖矿会占满磁盘。
du -sh /*  # 目录大小，找异常大文件。
mount  # 挂载信息。
find /tmp -type f  # 查找/tmp下可疑文件。

九、基础文本处理（日志过滤，SOC 天天用）。

grep  # 关键词搜索日志。
grep -i  # 忽略大小写。
grep -v  # 排除匹配行。
awk  # 截取日志字段。
sed  # 文本替换、过滤。
sort  # 排序。
uniq -c  # 统计重复次数。
head / tail  # 看文件头部尾部。
less  # 分页看大日志文件。

十、其他应急常用。
history  # 当前用户命令历史，看攻击者执行过什么命令。
w  # 当前在线登录用户。
curl / wget  # 确认服务器是否对外下载恶意文件。
systemctl list-unit-files  # 查看开机自启服务，找恶意服务。
systemctl status sshd。

十一、示例组合（工作真实写法）。

-grep "Failed password" /var/log/secure | awk '{print $11}' | sort | uniq -c。
作用：统计爆破SSH的源IP和次数。

-uname -a、last、lastb、cat /etc/passwd、ps aux、ss -tulnp、crontab -l。
-grep 日志过滤、tail /var/log/secure、journalctl、find SUID、w、history。

-nmap -sn ip 只扫描开机主机。
