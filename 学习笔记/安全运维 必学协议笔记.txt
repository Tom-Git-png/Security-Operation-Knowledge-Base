1. HTTP 超文本传输协议：

- 默认端口：TCP 80。
- 作用：明文浏览网页，浏览器和 Web 服务器通信。
- 关键特点：全部明文传输，请求头、Cookie、参数、POST 提交数据流量抓包全部可见。

正常行为。

GET/POST 访问网页资源，返回 200、302、404 等状态码。

SOC 蓝队关注点（告警 / 威胁）。

1. 明文传输账号密码，流量抓包直接泄露；
2. Webshell 大多走 HTTP/POST 上传执行命令；
3. SQL 注入、文件上传、XSS 全部依托 HTTP；
4. 异常 URI：`/eval.php`、`/shell.asp`、大量`cmd=`命令参数；
5. User‑Agent 异常（空 UA、恶意工具 UA）；
6. 大量 404、403 代表暴力扫描。

日志来源：access.log IIS/Apache/Nginx 日志、防火墙流量日志。

2. HTTPS HTTP‑Secure。

- 默认端口：TCP 443。
- 作用：HTTP + TLS/SSL 加密，网页流量密文传输。
- 关键点：payload 内容加密，抓包看不到请求体，但是能看到：源 IP、目的 IP、端口、TLS 握手信息、域名 (SNI)、证书信息 。

正常行为。

企业业务网站、对外服务，浏览器访问。

SOC 关注点。

1. 加密隧道：攻击者常用 HTTPS 做C2 远控回连，流量加密，传统防火墙无法看到内部恶意载荷；只能靠证书、SNI、IP、流量行为检测。
2. 异常 TLS：自签名证书、过期证书、异常 SNI 域名；
3. 内网主机主动对外 443 陌生外网 IP 大量通信，警惕木马回连；
4. 无法读取报文内容，需要开启 SSL 解密才能看到内部 HTTP 载荷。

区分记忆：80 明文，443 加密。

3. DNS 域名系统协议。

- 默认端口：UDP 53（查询）；TCP 53（区域传输、大报文）。
- 作用：把域名 ([www.xxx.com](https://www.xxx.com)) 翻译成 IP 地址，上网必用。

正常行为。

内网主机向内部 DNS 服务器或者公共 DNS (223.5.5.5、114.114.114.114) 做域名解析。

SOC 高频威胁点（HVV 护网非常常见）。

1. DNS 隧道：恶意软件把命令、数据封装进 DNS 查询报文向外传输，C2 通信；
2. DNS 查询大量随机乱码子域名；
3. 内网机器直接访问外部陌生 DNS 服务器；
4. DNS 区域传输漏洞 `AXFR`，攻击者批量导出全部域名；
5. 恶意域名解析：主机解析到 IOC 恶意 IP。

SOC 分析点：看 DNS 日志，哪些主机解析恶意域名，是否大量奇怪随机域名。

4. ICMP 互联网控制报文协议。

- 端口：没有端口！属于网络层协议，不是 TCP/UDP。
- 常见用途：`ping`、`traceroute`路由追踪。
- 类型：type=8 echo‑request 请求；type=0 echo‑reply 应答。

正常行为。

运维 ping 测试连通性。

SOC 威胁。

1. ICMP 隧道：木马把数据藏在 ping 包里面外传；
2. ICMP 洪水 DDOS 攻击；
3. 大量 ICMP unreachable 代表扫描行为；
4. 很多企业边界防火墙会直接禁止外网 ICMP。

SOC 小知识点：流量日志看到大量 ICMP，没有 TCP/UDP，就要怀疑隧道。

5. SSH 安全外壳协议。

- 默认端口：TCP 22。
- 作用：加密远程登录 Linux 服务器，远程命令执行、文件传输 sftp。

正常行为。

运维人员堡垒机登录 Linux 服务器。

SOC 告警高频场景。

1. SSH 暴力破解：大量源 IP 尝试账号密码登录；日志出现大量`Failed password`；
2. 成功异常登录：陌生 IP 登录服务器，非工作时间登录；
3. 攻击者爆破 SSH 拿到服务器权限；
4. SSH 隧道转发，做内网穿透，C2 通信。

日志源：`/var/log/secure`(CentOS) `/var/log/auth.log`(Ubuntu)，SIEM 里重点监控 SSH 登录失败、成功事件。

实战：HVV 里面 22 端口是被爆破重灾区。

6. RDP 远程桌面协议。

- 默认端口：TCP 3389。
- 作用：Windows 远程图形化桌面登录。

正常行为。

运维管理 Windows 服务器，一般走堡垒机访问。

SOC 蓝队重点。

1. 暴力破解重灾区：大量 RDP 登录失败事件；
2. 外网直接暴露 3389 高危；攻击者爆破拿到 Windows 主机权限；
3. RDP 横向移动：攻击者在内网拿到一台机器，通过 3389 登录其他主机；
4. 日志：Windows 事件 ID  4625 登录失败，4624 登录成功。

SOC L1 必记事件 ID：4625 失败，4624 成功。看到大量 4625 告警就要高度警惕。

7. FTP 文件传输协议。

- 默认端口：TCP 21（控制端口）；主动模式 20 数据端口。
- 特点：明文协议！账号密码、传输内容抓包可见。

正常行为。

业务文件上传下载。

SOC 风险。

1. 明文传输账号密码；不推荐生产使用，优先替换为 SFTP (SSH 22 端口)；
2. FTP 暴力破解；
3. 匿名 FTP 开启（anonymous），任何人可以登录下载上传文件；
4. 攻击者上传恶意文件。

扩展：SFTP 是基于 SSH22 端口加密，不要和传统 FTP 混淆。

8. SMB 服务器消息块协议。

- 默认端口：TCP 445；旧版 NetBIOS 139。
- 作用：Windows 局域网文件共享、打印机共享；域环境核心协议。

SMBv1 版本存在著名永恒之蓝漏洞 MS17‑017。

正常行为。

内网 Windows 机器之间访问共享文件夹；域控制器通信。正常业务不应该对外网开放 445！

SOC 最高优先级威胁（护网 HVV 高频）。

1. 永恒之蓝漏洞利用 SMBv1 传播勒索病毒；
2. 内网横向移动：攻击者拿到权限后通过 SMB 访问共享、投放后门；
3. 外网出现 445 访问流量几乎都是攻击扫描；
4. SMB 暴力破解，抓取哈希（hash）。

SOC 铁律：445 端口严禁暴露公网。SIEM 告警看到外网源访问内网 445，直接高风险告警。

常见状态码。

- 2xx 成功：200 OK；201 Created。
- 3xx 重定向：301 永久重定向；302 临时重定向；304 缓存未修改。
- 4xx 客户端错误：400 参数错误；401 未认证；403 禁止访问；404 找不到页面。
- 5xx 服务端错误：500 服务器内部错误；503 服务不可用。
